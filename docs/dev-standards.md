# 开发规范

## UI 图标规范

**禁止使用 Unicode 字符（含 emoji）作为 UI 图标。**

### 原因

1. **渲染兼容性**：不同操作系统和字体对 Unicode 符号的渲染存在差异，emoji 在部分设备上可能显示为方块、问号或完全不同的样式。
2. **文本搜索/复制**：Unicode 图标在文本选择、复制、搜索时会被当作字符处理，可能产生意料之外的结果。
3. **屏幕阅读器**：emoji 会被屏幕阅读器朗读 emoji 名称而非功能描述，影响无障碍体验。
4. **视觉一致性**：文字标签在所有设备和字号下显示一致，Unicode 符号则可能因字体缺失而变形。

### 正确做法

使用文本标签代替 Unicode 图标：

| 错误（Unicode/Emoji） | 正确（文字标签） |
|----------------------|------------------|
| 🎤 (麦克风) | "语音" |
| 📷 (相机) | "扫描" |
| 📋 (剪贴板) | "复制" |
| ► (播放) | "发送" |
| 🔧 (扳手) | "[工具]" |
| ✓ (勾号) | "[完成]" |
| ⚠ (警告) | "[警告]" / "[不安全]" |
| 🔴🟢 (状态点) | "!" / "-" 或文字 |
| ✅❌ (勾叉) | "[通过]" / "[拒绝]" |
| 🔄 (循环) | "重连" / "刷新" |
| ⋯ (省略号) | "..." |
| ⚡ (闪电) | "[命令]" / "[钩子]" |

### 例外

- 代码文档中的描述性 emoji（非 UI 交互元素）
- 用户输入的原始消息内容（在终端输出中保留原样）
- 系统栏/导航使用的标准 Unicode 箭头（← →）或数学符号（+ -）

### 检查清单

新 UI 元素提交前确认：
- [ ] 没有使用 emoji 作为按钮/标签图标
- [ ] 所有交互元素使用文字描述而非符号
- [ ] Toast 消息使用完整中文描述而非符号缩写
