# Serein V1.0 用户手册

## 1. 软件概述

Serein 是一套面向 HarmonyOS 手机的自托管 Agent 会话桥接软件。它把电脑上
Claude Code 与 OpenAI Codex CLI 的项目会话传到手机，并在 Claude Code 执行
高风险工具操作时提供远程审批。

软件由四部分组成：HarmonyOS 原生客户端、PC Relay、Go 后端和 Claude Code
审批 Hook。项目文件、Agent 进程和会话记录仍保留在用户自己的电脑；后端只承担
配对、会话路由、审批状态和通知链路。

手机端提供项目、终端、审批记录和设置等操作入口。电脑端负责实际运行 Agent，手机
端只发送经过身份校验的会话与控制请求，不替代电脑上的项目目录和开发环境。

## 2. 运行环境

- 手机：支持当前应用包的 HarmonyOS 设备；
- 电脑：Windows，已安装 Node.js、Python 3，以及 Claude Code 或 Codex CLI；
- 后端：可由用户在本机或自己的服务器部署，生产环境应使用 HTTPS/WSS；
- 网络：手机与后端、PC Relay 与后端之间需要可达。

## 3. 安装与初始化

1. 部署 Go 后端并设置生产环境变量、Hook Token 和非默认配对码；
2. 在电脑安装 CLI：`npm install -g @serein/cli`；
3. 运行 `serein init` 生成 Claude Code Hook 配置；
4. 运行 `serein doctor`，确认 Node、Python、Agent CLI、Hook 与后端状态；
5. 在手机安装经过签名的 HarmonyOS 应用；
6. 运行 `serein pair`，由手机扫描二维码完成单设备绑定。

初始化不会覆盖已经存在的后端地址和 Token。诊断命令不会输出完整 Token。
首次配对成功后，应在设置页确认设备状态、通知权限和后端连接状态，再开始启动项目。
更换手机前应先撤销当前设备，旧设备 Token 失效后才能完成新的单设备绑定。

## 4. 项目与 Agent

在项目目录执行 `serein` 或 `serein start` 可以启动当前项目。也可以运行
`serein daemon`，等待手机从已登记项目中发起启动。每个项目可以选择 Claude Code
或 Codex CLI；不支持的 Agent 会在启动前被拒绝。

手机项目页显示项目名称、在线状态和当前 Agent。启动与停止操作通过后端转发到
电脑 Relay，不能创建用户未登记的本地目录。
启动请求成功后，项目卡片显示真实运行状态；停止请求会关联当前会话和进程标识，
不会无条件终止电脑上的其他程序。状态变化由事件与心跳共同校正。

## 5. 手机终端

终端页接收 Agent 的结构化消息、工具步骤和最终回复，并允许用户输入文本、命令或
会话选项。短时断网时，尚未发送的输入会保留在本地队列；重连后按顺序继续发送。
用户可以调整字号、复制终端内容，并在项目之间切换。
当 Agent 返回目录信任、升级提示、额度提示或编号选项时，终端会将其作为交互内容
显示，用户完成选择后会话才继续执行。最终回复到达后，思考状态会及时结束。

## 6. 风险审批

Claude Code 工具调用首先由本地 Hook 分类：

- 绿色：只读或低风险操作，按规则自动放行；
- 黄色：可记录、可通知的普通写操作，按配置处理；
- 红色：删除、提权、推送等高风险操作，必须由手机明确允许或拒绝。

后端不可用、连续请求失败或审批超时后，系统默认拒绝，不会为了保持任务运行而
自动放行。审批、加密、PIN 与后台通知共同构成软件的安全链路。
审批详情包含项目、工具、风险原因和当前状态。用户作出决定后，同一审批不能重复
生效；网络重试也不会生成第二条有效审批记录。

## 7. 监控与通知

首页展示从电脑真实采集的 CPU、内存、磁盘和 GPU 数据；无法准确获取的字段应显示
不可用，不伪造百分比。应用在后台时，关键审批通过系统通知链路提醒用户；普通终端
输出不应冒充高风险通知。
用户主动刷新时会显示加载状态，请求结束后停止刷新动画；静默心跳更新不会移动首页
布局。无法准确采集的硬件字段显示不可用，不使用估算值替代真实数据。

## 8. 安全与隐私

- Hook Token 与设备 Token 分离，客户端不能冒充 Hook 创建审批；
- 会话数据使用 TLS/WSS 传输，支持的会话链路使用 AES-256-GCM 保护；
- Token 不在界面完整展示，不写入普通日志或未经授权的导出文件；
- 生产环境拒绝默认密钥和不安全配置；
- 单设备绑定要求先解绑当前手机，其他手机才能重新绑定；
- 高风险动作在基础设施异常时失败关闭（fail closed）。

用户应自行保护服务器、域名、系统账户和 Agent 凭证，并只对可信项目授予工具权限。
公网部署应使用有效 HTTPS/WSS 证书和随机安全参数。日志排查完成后应及时清理临时
导出文件，不把设备 Token、Hook Token 或 Agent 登录凭证发送给无关人员。

## 9. 故障排查

1. 手机离线：先运行 `serein doctor`，检查后端健康、设备 Token 和 Relay；
2. 项目无法启动：确认项目目录存在、Agent CLI 可在普通终端启动；
3. 审批不出现：检查 Hook 配置、Hook Token、通知权限和后端日志；
4. 会话无回复：确认 Relay WebSocket 在线，再检查 Agent 本地终端是否停在交互选项；
5. 版本不一致：重新构建并安装同一 V1.0 发布快照产生的应用包。

排查时先确认后端健康，再确认 Relay 和 Agent 进程，最后检查手机设备身份和通知
权限。该顺序可以区分服务不可达、电脑会话未运行和手机鉴权失效三类问题。

## 10. V1.0 功能范围

本手册描述 Serein V1.0 的项目登记与状态管理、Claude Code 与 Codex CLI 会话桥接、
手机终端交互、风险分类与审批、后台通知、链路加密、单设备绑定、系统监控、设备撤销
和紧急停止功能。手机只操作用户已经在电脑端登记的项目；高风险操作必须由绑定设备
明确允许或拒绝。
