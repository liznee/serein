# Serein V1.0 产品边界

> 更新日期：2026-08-18
> 公开版本：1.0.0 Release Candidate
> 原则：现有产品功能全部开放源码；按成熟度分层，不按付费状态裁剪。

## 1. 一个公开功能集

Serein V1.0 不再维护“社区精简版”和“个人完整版”两套功能集。公开导出保留远程桌面、社区工作流和 Codex Desktop 接入，只负责移除以下内容：

- 私人服务器地址、Token、OAuth Secret 和账号信息；
- HarmonyOS 个人签名、证书与密码；
- 数据库、日志、缓存、编译产物和测试截图；
- 仅用于个人运维且包含本机路径或服务器拓扑的材料。

`ProductFeatures.ets` 中的布尔值只用于缺少平台依赖时的编译兼容，不是产品版本或付费门禁。公开源码默认启用当前已有能力。

## 2. 稳定核心

- 本地项目注册、选择、启动、停止和状态同步；
- Claude Code CLI 与 OpenAI Codex CLI 会话；
- 手机端实时终端输入、输出、历史恢复和断线重连；
- 风险分级、工具审批、审批记录和紧急停止；
- 后台通知、连接状态与基础系统监控；
- 单设备配对、自托管后端和本地 Relay；
- PIN / 生物识别入口保护、Token 校验和会话加密；
- 公开部署文档、诊断命令和可复现构建流程。

安全能力不得通过版本开关降级：工具审批、危险命令拦截、Token 脱敏、安全存储、传输加密、设备撤销、超时拒绝和紧急停止始终存在。

## 3. 开放的实验功能

| 能力 | V1.0 状态 | 使用边界 |
|---|---|---|
| 远程桌面与触控 | 实验，源码开放 | 屏幕捕获和输入注入需要明确授权；公网使用应配置 TURN/TLS 并独立审计 |
| GitHub/Gitee 社区 | 实验，源码开放 | OAuth 可选；外部内容一律视为不可信；写回仍需用户确认 |
| Codex Desktop 会话 | 实验，源码开放 | 依赖 Codex App Server 行为，协议变化可能影响发现和恢复 |
| Issue 写回、PR/MR、CI 流程 | 分阶段开放 | 外部写操作必须细粒度授权并保留审计记录 |

“实验”表示兼容性、稳定性或真机证据尚未达到稳定核心的标准，不表示需要付费，也不表示通过隐藏入口掩盖风险。

## 4. 未来商业化边界

在软著、应用商店和支付链路尚未完成前，不设置本地付费墙。未来若产生收费服务，优先对应真实持续成本：

1. 托管 Relay、TURN、OAuth 回调、监控、备份与自动更新；
2. 团队成员、RBAC、共享策略、集中审计与企业部署；
3. SLA、兼容性维护、迁移协助和商业技术支持；
4. 应用商店分发、自动更新等便利服务（以平台规则允许为前提）。

MIT 代码用户可以自行构建和修改。商业化不能依赖一个可被改掉的客户端布尔值，也不能靠削弱安全能力制造付费需求。

## 5. 发布定义

V1.0 RC 的质量表述是：已通过记录中的自动化门禁，但 Push Kit 正式身份、干净机器安装和同一台真机关键链路回归仍未全部完成。软件工程无法证明“绝对零 Bug”；未完成验证的能力必须明确标注实验或已知限制，不能使用宣传语冒充证据。
