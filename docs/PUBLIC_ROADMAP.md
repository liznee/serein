# Serein 开源路线图

## V1.0：一个完整的开源候选版

- HarmonyOS 原生客户端；
- Claude Code 与 Codex CLI 项目会话；
- 手机实时终端、断线重连和会话恢复；
- Claude Code 风险分级与远程审批；
- 后台通知、单设备配对和基础系统监控；
- 自托管 Go 后端、PC Relay 和诊断命令；
- 远程桌面、GitHub/Gitee 社区与 Codex Desktop 实验功能；
- 可复现的公开导出、CI、依赖审计和构建流程。

现有功能全部进入公开源码。稳定核心和实验功能使用同一份代码，但在界面、文档和测试证据中明确区分成熟度。

V1.0 正式发布仍需完成真机关键链路回归、Push Kit 正式身份验证和干净机器安装。

## V1.x：质量与兼容性

- 优化弱网重连、状态一致性和通知到达率；
- 补齐可观测性、故障导出和 Token 轮换；
- 提升 Codex CLI 选项和工具审批兼容性；
- 完善远程桌面、社区和 Codex Desktop 的安全审计与真机证据；
- 建立真机性能基线，并据此持续优化终端、通知与远程控制延迟。

## 可选托管与商业服务

- 托管 Relay、TURN、OAuth、监控、备份和升级；
- 团队成员、RBAC、共享策略和集中审计；
- 企业部署、SLA、迁移与兼容性支持。

这些服务可以收费，但不会把已经进入 MIT 仓库的本地功能重新锁起来。审批、加密、PIN、通知、设备撤销和紧急停止始终属于安全基线。
